# Standin Landing Documentation

이 폴더는 Claude를 통해 Standin 랜딩페이지를 제작하기 위한 문서 세트입니다.

- 루트의 `CLAUDE.md`: Claude가 가장 먼저 읽을 작업 지침
- `docs/`: 제품, 랜딩페이지 구조, UI, 카피, 컴포넌트, 구현, 에셋 가이드

권장 시작 프롬프트:

> 루트의 CLAUDE.md와 docs 폴더 문서를 모두 읽고, 문서 우선순위와 제품 범위를 지켜 Standin 반응형 랜딩페이지를 구현해줘. 먼저 현재 프로젝트 구조를 확인한 뒤, 구현 계획을 짧게 정리하고 작업을 시작해줘. 구현되지 않은 AI 기능을 실제로 동작하는 것처럼 만들지 말고 제품 흐름 예시로 표현해줘.
