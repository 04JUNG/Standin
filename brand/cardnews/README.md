# Standin 소개 카드뉴스

랜딩페이지 UI 톤(잉크 네이비 + 코랄 포인트 + 그리드 텍스처 + 워드마크)으로 만든
서비스 소개 카드뉴스 6장입니다. 1080×1080 정사각(인스타그램/카드뉴스 규격).

## 구성

| 파일 | 카드 | 내용 |
|---|---|---|
| `1-cover.png` | 커버 | 서비스 한 줄 소개 |
| `2-team.png` | 팀 소개 | 팀 소개 + **소속(소프트웨어 마에스트로)** 스트립 |
| `3-problem-time.png` | 문제 1 | 웹툰 작가의 창작 시간(주 6일·9.5시간 등) |
| `4-problem-3d.png` | 문제 2 | 3D 배치의 번거로움(빈 인형·에셋 탐색·반복 배치) |
| `5-solution.png` | 해결 | Standin 4단계 흐름 + "작가가 선택" 원칙 |
| `6-cta.png` | CTA | 베타 대기 등록 안내 |

각 카드의 편집용 벡터 소스는 같은 이름의 `*.svg` 입니다.

## PNG 재생성

```bash
npm i -D @resvg/resvg-js   # 최초 1회
node brand/cardnews/gen-cards.mjs
```

폴더 안의 모든 `*.svg`를 1080×1080 PNG로 렌더링합니다.

## ⚠️ 확인이 필요한 부분

- **문제 1 카드의 통계 수치(36.9% / 5.8일 / 9.5시간)**는 제공된 인포그래픽 이미지를
  기준으로 옮긴 값입니다. 실제 게시 전 **원 출처(조사기관·조사명·연도)를 확인해
  `3-problem-time.svg` 하단 각주에 정확히 표기**하세요. (현재는 "조사기관·연도 표기 권장"
  플레이스홀더 상태)
- **팀 소개 카드**는 팀명·구성원 등 확정 정보가 없어 일반 소개 문구로 작성했습니다.
  필요 시 `2-team.svg`에서 실제 팀 정보로 교체하세요.
- **소속 로고(소프트웨어 마에스트로 / 과학기술정보통신부 / IITP / FKII)** 는 상표 문제로
  실제 공식 로고 대신 **브랜드 톤에 맞춘 로고 스타일 목업(엠블럼+명칭)**으로 표현했습니다.
  게시용으로는 각 기관의 **공식 로고 이미지로 교체**하세요. 로고 파일(PNG/SVG)을 주면
  `2-team.svg`에 `data:` URI로 임베드해 실제 로고로 렌더링할 수 있습니다.

## 폰트

브랜드 폰트는 Pretendard이며, 미설치 환경에서는 렌더 시 Malgun Gothic으로 대체됩니다.
Pretendard 설치 후 재생성하면 브랜드 폰트로 렌더링됩니다.
