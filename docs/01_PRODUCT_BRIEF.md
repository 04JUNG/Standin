# Standin 제품 브리프

## 1. 한 줄 정의

**Standin은 러프 콘티에서 사용할 만한 3D 인체 포즈 후보를 찾아, 웹툰 작가의 반복적인 3D 배치 작업을 줄이는 어시스트 도구다.**

---

## 2. 이름의 의미

Stand-in은 촬영 현장에서 배우 대신 위치와 동선을 잡아주는 대역을 뜻한다.

Standin의 3D 인체도 작가의 그림을 대신 완성하지 않는다. 대신 콘티와 밑그림 사이에서 포즈와 구도를 잡는 임시 기준점이 되어준다.

브랜드 메시지:

> 완성은 작가가. 시작점은 Standin이.

---

## 3. 해결하려는 문제

웹툰 작가는 복잡한 인체 비율과 구도를 잡기 위해 클립스튜디오 등의 3D 인체 소재를 활용한다. 그러나 매 컷마다 다음 작업을 반복해야 한다.

- 적절한 3D 인체 소재 찾기
- 포즈를 직접 조정하기
- 인물의 방향과 위치 배치하기
- 카메라 각도 맞추기
- 다시 작화 환경으로 옮기기

특히 전신, 반신, 다인 구도처럼 인체 구조가 복잡한 컷에서 이 준비 과정의 부담이 크다.

---

## 4. 제안하는 해결 방식

Standin은 완벽한 포즈 하나를 자동으로 생성하는 대신, 콘티를 분석해 **가까운 3D 포즈 후보 여러 개를 제안**한다.

기본 흐름:

1. 러프 콘티 업로드
2. 컷과 인물 영역 파악
3. 2D 포즈와 장면 의미 분석
4. 포즈 라이브러리에서 유사 후보 검색
5. 사용할 만한 후보 제시
6. 작가가 선택하고 필요한 만큼 조정
7. 3D 파일 또는 참조 형태로 기존 작화 흐름에 연결

---

## 5. 핵심 사용자

### 1차 사용자

- 개인 또는 소규모 팀으로 작업하는 웹툰 작가
- 콘티부터 선화까지 직접 담당하는 그림 작가
- 클립스튜디오 3D 인체를 사용하지만 배치와 포징이 번거로운 사용자
- 인체와 원근이 복잡한 컷에서 작업 시간이 많이 드는 사용자

### 랜딩페이지에서 피해야 할 지나친 확장

- 애니메이션 스튜디오 전체 파이프라인
- 게임 캐릭터 애니메이션 제작
- 실사 모션 캡처 대체
- 일반 소비자용 3D 캐릭터 생성기

---

## 6. 가치 제안

### 빠른 시작점

빈 3D 인형에서 관절을 하나씩 잡는 대신, 콘티와 가까운 후보에서 시작한다.

### 선택권 유지

AI가 결과를 확정하지 않는다. 작가가 후보를 비교하고 직접 선택한다.

### 기존 작업 흐름 유지

Standin 안에서 모든 작화를 끝내게 강요하지 않는다. 3D 배치를 준비한 뒤 클립스튜디오에서 이어서 그린다.

### 필요한 컷에 집중

얼굴 클로즈업처럼 3D 전신이 큰 도움이 되지 않는 컷까지 억지로 자동화하지 않는다. 전신·반신 등 작가가 실제로 어려워하는 컷에 집중한다.

---

## 7. MVP 범위

현재 제품 소개는 아래 범위 안에서 이루어져야 한다.

### 핵심 범위

- 러프 콘티 입력
- 컷 분리
- 인물 및 2D 포즈 파악
- 포즈 검색
- 상위 후보 제시
- 작가 선택
- 클립스튜디오 활용을 위한 내보내기 흐름

### 제한 범위

- 장르 1개 중심
- 인물 2명 이하 우선
- 전신·반신 위주
- 극단적 클로즈업 및 복잡한 가림은 폴백 또는 수동 처리

### 현재 기능처럼 말하지 않을 항목

- 카메라·위치·회전·스케일의 완전 자동 최적화
- 복잡하게 얽힌 다중 인물의 완전 자동 배치
- 모든 그림체에 대한 안정적인 자동 인식
- 모든 포즈를 생성하는 범용 모델

---

## 8. 차별화 관점

Standin은 단순한 3D 포즈 라이브러리도, 이미지 생성 서비스도 아니다.

| 구분 | 일반 방식 | Standin |
|---|---|---|
| 시작점 | 사용자가 포즈를 직접 검색 | 콘티를 검색 쿼리로 사용 |
| 결과 | 하나의 소재 또는 빈 인형 | 가까운 후보 여러 개 |
| 결정 | 도구 또는 사용자가 처음부터 제작 | 작가가 후보 중 선택 |
| 목적 | 3D 제작 자체 | 웹툰 작화 준비 시간 단축 |
| 작업 환경 | 별도 툴 중심 | 클립스튜디오 흐름에 연결 |

---

## 9. 브랜드 성격

- 창작자를 존중한다.
- 기술을 과장하지 않는다.
- 빠르고 명료하다.
- 작가의 판단을 빼앗지 않는다.
- 전문적이지만 차갑지 않다.
- 실험적인 AI 서비스보다 믿을 수 있는 제작 도구에 가깝다.

---

## 10. 핵심 메시지 우선순위

1. 러프 콘티에서 3D 포즈의 시작점을 찾는다.
2. 완성된 답 하나가 아니라 사용할 만한 후보를 제안한다.
3. 작가가 선택하고 조정한다.
4. 클립스튜디오 작업으로 자연스럽게 이어진다.
5. 모든 컷이 아닌, 3D가 실제로 필요한 컷에 집중한다.
