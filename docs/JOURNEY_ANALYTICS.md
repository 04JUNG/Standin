# 웹 방문 경로 분석 (2026-11-09)

측정 기본값은 거절입니다. 새 v3 선택은 Standin·GA4 분석과 Meta 광고 측정을 따로 제공하고, 이전 v2 거절을 유지하되 이전 허용을 새 분석 동의로 간주하지 않습니다. 계정·설문·약관 및 알 수 없는 쿼리에서는 측정기를 시작하지 않습니다.

`journey.ts`는 허용한 방문자만 임의 쿠키를 발급합니다. 페이지·구간 진입, 독점 활성 체류 시간, 25% 단계 스크롤, 알려진 CTA, 다운로드·앱 열기·PC 링크 복사와 숨김/떠남을 고정된 enum으로 기록합니다. 폼 값·문장·전체 URL·클릭 ID·DOM 텍스트·마우스 좌표는 수집하지 않습니다. 10초마다 최대 30건을 보내고 실패 시 동일 UUID로 재시도합니다. 쿠키는 host-only Secure/SameSite=Lax, 요청은 credentials omit/no-referrer입니다.

체류 시간은 visible + focus + 최근 60초 내 활동 조건을 만족한 구간 하나에만 적립합니다. 숨김·종료의 마지막 배치는 누락될 수 있으며 ‘이탈’은 마지막 관측으로만 해석합니다. 내려받기 버튼 클릭은 파일 수신·설치 완료가 아닙니다.

웹 분석 허용 시 일회용 handoff를 메모리로 준비합니다. 최신 공개 앱이 v0.2.9 이상일 때 앱 열기 버튼의 사용자 클릭으로만 전달합니다. 연결값을 앵커 href나 GA4/Meta 이벤트에 넣지 않습니다. 앱에서 별도 선택 동의해야 개별 방문과 이후 이용이 연결됩니다. 일반 설치 파일의 직접 실행에는 방문별 코드가 포함되지 않습니다.

철회 시 큐·타이머를 즉시 중단하고 쿠키와 서버 기록을 삭제합니다. 삭제가 실패하면 완료로 표시하지 않고 최소 capability를 삭제 재시도 용도로만 보관합니다. 저장소 차단 시 현재 문서의 메모리에서만 재시도할 수 있습니다. 개인정보 고지 제8항과 화면의 수집 범위를 함께 유지해야 합니다.

배포 순서: 서버 경로/스키마 → 랜딩 고지/동의 → 승인된 앱 v0.2.9 공개. `npm run check:measurement`, `npm run lint`, `npm run build` 및 PC/모바일 화면 확인. 운영 데이터로 테스트 이벤트를 만들지 않습니다.
