## 원본과 웹용 추출

원본: 형제 저장소 `Standin-master-docs/오픈베타_영업_준비/약관_정책/01~04`의 Markdown. 원본 MD/TXT의 날짜·주체를 함께 갱신했다.

`npm run sync:legal`은 원본의 내부 작성 메모, 조사·개발 지시를 제외하고 `src/content/legal/`에 전문을 복사한다. 문서 페이지는 이 전문을 안전한 React 텍스트로 렌더링하며 원시 HTML은 실행하지 않는다. 개발 서버용 TXT도 `public/legal/`에 생성한다. 일반 빌드는 형제 저장소에 접근하지 않고 저장된 사본을 사용한다. 원본을 수정한 뒤 동기화 결과를 검토하고 빌드한다.

일정 변경의 세부 고지 기준 같은 작성 메모는 웹에서 제외하되 기존 사전 안내 의무는 유지했다. 베타 일정은 10월 21일~11월 18일 **예정**으로 남겼고, 지원 환경은 설치 파일 제공 시 안내하도록 표현했다. 원본에서 요구한 운영 서버 한도·실패 복원·취소 기능·실제 삭제 동작 검증을 완료한 것으로 취급하지 않는다.

## 아직 확정되지 않은 내용

개인정보처리방침에는 실제 계약·이전 국가·연락처, 증빙 보관 근거, 기존 신청정보 처리 및 실제 삭제·보안 구현의 미확정 항목이 남아 있다. 동의 종료·권리행사 처리 완료 후 최대 1년의 최소 증빙 보관과 Gmail 소량 직접 발송·답장 수신거부는 추가 답변으로 확정했다. 해당 페이지와 TXT는 검토본이며 아직 적용되지 않은 정책을 포함한다고 명시한다. 약관 페이지는 현재 모두 `noindex`이며 사이트맵에 넣지 않았다. `noindex`는 접근 제한이 아니다. 사용자가 미확정·구현 차이 안내 후 2026-10-19 “배포해줘”라고 요청하여 웹 푸터·문서 경로를 공개한다. 이 요청은 개인정보처리방침의 최종 확정이나 앱 보관·동의 기능의 적용 완료를 뜻하지 않는다.

사용자의 대한민국 처리·90일 보관 답변을 모든 외부 사업자의 계약 조건으로 확대하지 않았다. 로컬 분석 코드는 API 키 기반 `google-genai` 호출이고, Google의 공식 유료 Gemini API 약관은 해외 시설에서의 임시 저장·캐시 가능성을 안내한다. 유료 서비스의 입력·응답은 제품 개선에 이용하지 않지만 보안 목적 기록에는 별도 조건이 있다.

- [Gemini API 유료 서비스 약관](https://ai.google.dev/gemini-api/terms): 유료 입력·응답의 제품 개선 미사용, 해외 임시 저장 가능성.
- [보안 목적 보관 안내](https://ai.google.dev/gemini-api/docs/usage-policies): 55일 보관, 정책 집행 목적 모델의 예외. 확인일 2026-10-19.

확인된 국내 서버 처리와 외부 서비스의 처리 조건을 분리하여 원본·웹용 방침에 반영했다. Google의 실제 이전 국가를 추측하여 채우지 않았다.

기존 랜딩의 사전등록 폼·혜택과 초안의 직접 다운로드 정책, 앱·BFF의 동의·삭제 동작은 이번 푸터 작업으로 전환되지 않았다. 개인정보 공개본을 확정할 때 실제 수집 경로와 일치시켜야 한다.

2026-10-19 추가 확인: 공개 사이트 번들에는 Apps Script 접수 URL과 UTM·pageUrl·userAgent 항목이 남아 있다. 로컬 Apps Script의 Discord 알림에는 이메일·설문 응답도 포함된다. 실제 배포된 스크립트·시트·웹후크 설정은 미조회다. AWS 재로그인 후 운영 S3 일괄 90일·서버 로그 14일·RDS 자동 백업 7일·별도 수동 스냅샷 1개를 확인했다. 실행 중 BFF 이미지도 점검한 소스와 일치한다. 최신 정책에서 기본 원본을 90일로 변경했지만 앱의 단일 필수 동의·DB 이력 365일·전체 삭제 누락은 여전히 차이가 있다. 출처·운영 확인·최신 결정은 master-docs의 08번 제12~14절을 따른다. 이번 웹 변경으로 앱·서버 저장·동의 기능을 수정한 것은 아니다.

## 검증·게시

`npm run build`는 타입 검사, 정적 HTML 생성, 기존 SEO 검사, 약관 전문·날짜·TXT·목차·푸터 검사까지 수행한다. `npm run lint`는 저장소 CI 기준의 정적 검사다.

검토본 공개에는 `npm run sync:legal`, `npm run build`, `npm run lint`로 문서 동기화·렌더링·초안 표시를 검증한다. 최종 개인정보처리방침으로 전환하기 전에는 미확정 사실과 실제 서비스 동작을 확인하고 `npm run check:legal-release`도 통과해야 한다. 이 명령은 현재 미확정 문서 때문에 실패하며 검사를 제거하거나 통과한 것으로 기록하지 않는다. 검사는 계약·법률·서비스 구현 검토 자체를 대신하지 않는다. 앱의 동의 버전은 이번 웹 수정에서 변경하지 않았다.
