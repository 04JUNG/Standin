# Standin hero pose assets

Vizcom식 러프·3D 부분 공개 인터랙션을 검토하기 위한 1차 생성 에셋이다.

## 파일 구성

- `pose-sport-*`: 폭발적으로 출발하는 스포츠 포즈
- `pose-baseball-*`: 공을 놓은 직후의 야구 투수 포즈
- `pose-basketball-*`: 의상·신발·장갑 없이 표현한 낮은 크로스오버 드리블 포즈
- `pose-action-*`: 낮은 전방 런지 액션 포즈
- `pose-dynamic-*`: 공중 회전 점프 포즈
- `pose-arch-*`: 허리를 뒤로 젖히고 팔다리를 접은 공중 백아치 포즈
- `pose-showcase-action-*`: 사용자가 제공한 액션 러프·3D 세트
- `pose-showcase-run-*`: 사용자가 제공한 달리기 러프·3D 세트
- `pose-showcase-spin-*`: 사용자가 제공한 공중 회전 러프·3D 세트
- `pose-showcase-volleyball-*`: 사용자가 제공한 배구 공중 동작 러프·3D 세트
- `*-pair.png`: 생성 원본 좌우 비교 이미지
- `*-rough.png`: 왼쪽 러프 영역
- `*-mannequin.png`: 오른쪽 3D 인형 영역

각 분리 이미지는 768×1024px이며 같은 쌍 안에서 동일한 캔버스 크기를 사용한다. 현재 랜딩페이지 히어로에는 `pose-showcase-*` 네 세트를 사용한다.

## 사용 조건

- 이미지 생성 도구로 만든 콘셉트 에셋이며 실제 Standin 출력이 아니다.
- 외부 공개 시 실제 제품 결과로 교체하거나 `연출 예시`임을 명시한다.
- 러프와 3D 인형의 관절이 완전히 일치하는지 최종 공개 전에 다시 검수한다.
- 웹에서는 두 이미지를 같은 컨테이너에 절대 위치로 겹치고, 3D 이미지에 마스크를 적용한다.

## 생성 방식

- 도구: built-in image generation
- 참고 이미지 역할: 색감·러프선·3D 인형 재질 참고만 사용
- 공통 조건: 밝은 배경, 파란 연필 러프선, 흰색·하늘색 관절 인형, 동일 포즈와 카메라, 텍스트·로고·워터마크 제외
- 인체 조건: 러프와 3D 모두 옷·신발·장갑·보호대 없이 중립적인 포즈 마네킹으로 표현
- 포즈별 조건: 농구 크로스오버 드리블, 낮은 액션 런지, 공중 회전 점프
